# Aula 0.1.1

A small update with a new cursor and a few fixes. If you already have Aula 0.1.0, it updates itself.

## What's new
- A sun cursor, the same as in the film: Aula's sun leaves a short comet tail as it moves and a brick ripple when you
  click. You can switch back to the usual pointer in *Settings → Appearance → Cursor*.
- *Create document* greys out the kinds a course can't produce yet (for example flashcards, if the course has none) and
  tells you why, instead of failing with "Couldn't prepare the document".
- In the reader, Aula's answers no longer get stuck on "Reading the document…", and their page citations, like
  (p. 2), jump to that page again.
- The floating Aula button moves out of the way when a switch sits half under it.

## Install
| System | Download | First launch |
| --- | --- | --- |
| macOS 13 or later (Apple Silicon and Intel) | `Aula-0.1.1-mac.dmg` | Drag Aula to *Applications*. It isn't notarized yet: try to open it, then go to *System Settings → Privacy & Security → Open Anyway* (on macOS 14 and earlier, right-click → Open). |
| Windows 10 and 11 (x64 and ARM) | `Aula-Setup-0.1.1.exe` | If SmartScreen appears: *More info → Run anyway*. |
| Linux x64 | `Aula-0.1.1-linux-x86_64.AppImage` · `Aula-0.1.1-linux-amd64.deb` | `chmod +x` the AppImage and open it, or `sudo apt install ./Aula-0.1.1-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.1.1-linux-arm64.AppImage` | `chmod +x` the AppImage and open it. |

All the changes are in the [CHANGELOG](https://github.com/luumlabs/aula/blob/main/CHANGELOG.md).

# Aula 0.1.1

Una actualización pequeña con un cursor nuevo y algunos arreglos. Si ya tienes Aula 0.1.0, se actualiza sola.

## Lo nuevo
- Un cursor-sol, el mismo de la película: el sol de Aula deja una cola de cometa corta al moverse y una onda ladrillo al
  hacer clic. Puedes volver a la flecha de siempre en *Ajustes → Apariencia → Cursor*.
- *Crear documento* apaga los tipos que un curso todavía no puede dar (por ejemplo, las tarjetas si el curso no tiene) y
  te dice por qué, en vez de fallar con «No se pudo preparar el documento».
- En el lector, las respuestas de Aula ya no se quedan en «Leyendo el documento…», y sus citas de página, como (p. 2),
  vuelven a llevarte a esa página.
- El botón flotante de Aula se aparta cuando tiene un interruptor medio debajo.

| Windows 10 y 11 (x64 y ARM) | `Aula-Setup-0.1.1.exe` | Si aparece SmartScreen: *Más información → Ejecutar de todas formas*. |
