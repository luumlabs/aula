# Aula 0.2.4

Signing in to Moodle with your university's Microsoft account works again, Aula can run as a server without a Mac,
and there's an Android app.

If you have Aula 0.2.0 or later, it updates itself. **If you still have Aula 0.1.x, install this version by hand this
one time:** download it below and install it over your copy (your courses and settings stay). Aula 0.1.x will say this
version's signature isn't valid, because since 0.2.0 Aula is signed with new keys.

## What's new
- **Moodle with a Microsoft account, fixed** ([#25](https://github.com/luumlabs/aula/issues/25)): the sign-in window
  no longer gets stuck when Microsoft asks for a passkey (it tells you to choose *Other ways to sign in*), no longer
  closes before you accept Moodle's site policy or complete your profile, and no longer starts a second sign-in behind
  your back. When something outside Aula stops the sign-in (a VPN or proxy, a university that only lets registered
  devices in), the window says what.
- **Aula as a server:** run Aula without a window on a computer that is always on (a home server, a NAS, a Linux
  container: `ghcr.io/luumlabs/aula-server:0.2.4`) and use it from your iPad, iPhone or Android phone, over your own
  Tailscale network. The first device you link is its owner. Guide:
  [docs/SERVER.md](https://github.com/luumlabs/aula/blob/v0.2.4/docs/SERVER.md).
- **Aula for Android:** the same window to your Aula as on the iPad and iPhone, with Tailscale built in.

## Install
| System | Download | First launch |
| --- | --- | --- |
| macOS 13 or later (Apple Silicon and Intel) | `Aula-0.2.4-mac.dmg` | Drag Aula to *Applications*. It isn't notarized yet: try to open it, then go to *System Settings → Privacy & Security → Open Anyway* (on macOS 14 and earlier, right-click → Open). |
| Windows 10 and 11 (x64 and ARM) | `Aula-Setup-0.2.4.exe` | If SmartScreen appears: *More info → Run anyway*. |
| Linux x64 | `Aula-0.2.4-linux-x86_64.AppImage` · `Aula-0.2.4-linux-amd64.deb` | `chmod +x` the AppImage and open it, or `sudo apt install ./Aula-0.2.4-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.2.4-linux-arm64.AppImage` | `chmod +x` the AppImage and open it. |
| Android 8 or later | `Aula-0.2.4-android.apk` | Open the file on the phone and allow installing from that app when Android asks. It needs Aula running on your Mac or on a server. |
| Server (Docker, x64 and ARM64) | `ghcr.io/luumlabs/aula-server:0.2.4` | `docker run -d --name aula --restart unless-stopped --shm-size=1g -v aula-data:/data ghcr.io/luumlabs/aula-server:0.2.4`, then `docker logs aula`. |

All the changes are in the [CHANGELOG](https://github.com/luumlabs/aula/blob/main/CHANGELOG.md).

# Aula 0.2.4

Vuelve a funcionar el inicio de sesión en Moodle con la cuenta de Microsoft de tu universidad, Aula puede ir como
servidor sin Mac y hay app de Android.

Si tienes Aula 0.2.0 o posterior, se actualiza sola. **Si todavía tienes Aula 0.1.x, instala esta versión a mano esta
única vez:** descárgala abajo e instálala encima de tu copia (tus cursos y ajustes se quedan). Aula 0.1.x dirá que la
firma de esta versión no es válida, porque desde la 0.2.0 Aula va firmada con claves nuevas.

## Lo nuevo
- **Moodle con cuenta de Microsoft, arreglado** ([#25](https://github.com/luumlabs/aula/issues/25)): la ventana de
  inicio de sesión ya no se queda colgada cuando Microsoft pide una llave de acceso (passkey; te dice que elijas
  *Otras formas de iniciar sesión*), ya no se cierra antes de que aceptes la política de Moodle o completes tu perfil y
  ya no empieza un segundo inicio de sesión a tus espaldas. Cuando algo ajeno a Aula corta el inicio de sesión (una VPN
  o un proxy, una universidad que solo deja entrar desde equipos registrados), la ventana dice qué es.
- **Aula como servidor:** Aula sin ventana en un equipo siempre encendido (un servidor de casa, un NAS, un contenedor
  de Linux: `ghcr.io/luumlabs/aula-server:0.2.4`), y la usas desde tu iPad, tu iPhone o tu Android por tu propia red
  de Tailscale. El primer dispositivo que vinculas es el propietario. Guía:
  [docs/SERVER.md](https://github.com/luumlabs/aula/blob/v0.2.4/docs/SERVER.md) (en inglés).
- **Aula para Android:** la misma ventana a tu Aula que en el iPad y el iPhone, con Tailscale dentro.
