# Aula 0.2.1

Two fixes to Today, one of them for Aula on your phone.

If you have Aula 0.2.0, it updates itself. **If you still have Aula 0.1.x, install this version by hand this one
time:** download it below and install it over your copy (your courses and settings stay). Aula 0.1.x will say this
version's signature isn't valid, because since 0.2.0 Aula is signed with new keys.

## What's new
- **Today:** the tools at the bottom are drawn on the same hand-painted tiles, each with its own colour, as on the
  Tools screen.
- **Aula on your phone:** on Today, the small arch no longer covers the *Ask Aula* button.

## Install
| System | Download | First launch |
| --- | --- | --- |
| macOS 13 or later (Apple Silicon and Intel) | `Aula-0.2.1-mac.dmg` | Drag Aula to *Applications*. It isn't notarized yet: try to open it, then go to *System Settings → Privacy & Security → Open Anyway* (on macOS 14 and earlier, right-click → Open). |
| Windows 10 and 11 (x64 and ARM) | `Aula-Setup-0.2.1.exe` | If SmartScreen appears: *More info → Run anyway*. |
| Linux x64 | `Aula-0.2.1-linux-x86_64.AppImage` · `Aula-0.2.1-linux-amd64.deb` | `chmod +x` the AppImage and open it, or `sudo apt install ./Aula-0.2.1-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.2.1-linux-arm64.AppImage` | `chmod +x` the AppImage and open it. |

All the changes are in the [CHANGELOG](https://github.com/luumlabs/aula/blob/main/CHANGELOG.md).

# Aula 0.2.1

Dos arreglos en Hoy, uno de ellos para Aula en tu teléfono.

Si tienes Aula 0.2.0, se actualiza sola. **Si todavía tienes Aula 0.1.x, instala esta versión a mano esta única
vez:** descárgala abajo e instálala encima de tu copia (tus cursos y ajustes se quedan). Aula 0.1.x dirá que la firma
de esta versión no es válida, porque desde la 0.2.0 Aula va firmada con claves nuevas.

## Lo nuevo
- **Hoy:** las herramientas de abajo se dibujan en las mismas losetas pintadas a mano, cada una con su color, que en
  la pantalla Herramientas.
- **Aula en tu teléfono:** en Hoy, el arco pequeño ya no tapa el botón *Pregunta a Aula*.

## Instalar
| Sistema | Descarga | La primera vez |
| --- | --- | --- |
| macOS 13 o posterior (Apple Silicon e Intel) | `Aula-0.2.1-mac.dmg` | Arrastra Aula a *Aplicaciones*. Aún no está notarizada: intenta abrirla y luego ve a *Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente* (en macOS 14 y anteriores, clic derecho → Abrir). |
| Windows 10 y 11 (x64 y ARM) | `Aula-Setup-0.2.1.exe` | Si aparece SmartScreen: *Más información → Ejecutar de todas formas*. |
| Linux x64 | `Aula-0.2.1-linux-x86_64.AppImage` · `Aula-0.2.1-linux-amd64.deb` | Haz ejecutable la AppImage (`chmod +x`) y ábrela, o `sudo apt install ./Aula-0.2.1-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.2.1-linux-arm64.AppImage` | Haz ejecutable la AppImage (`chmod +x`) y ábrela. |

Todos los cambios están en el [CHANGELOG](https://github.com/luumlabs/aula/blob/main/CHANGELOG.md) (en inglés).

**Código fuente:** los archivos *Source code* de esta versión (etiqueta `v0.2.1`) son el código exacto de estos
instaladores, con la licencia [GNU AGPL v3](https://github.com/luumlabs/aula/blob/v0.2.1/LICENSE.md).
