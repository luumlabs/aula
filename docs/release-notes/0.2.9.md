# Aula 0.2.9

Use Aula on Windows as a private Tailscale host for your Android phone, iPhone and iPad — directly reusing your existing
Windows courses, progress and settings without Docker or a separate server — plus reliability and hardening fixes across
data resets, remote uploads and Windows updates.

If you have Aula 0.2.0 or later, it updates itself. On a Mac, copies from 0.2.0 to 0.2.4 update to 0.2.5 first and
then to 0.2.9. **If you still have Aula 0.1.x, install this version by hand this one time:** download it below and
install it over your copy (your courses and settings stay). Aula 0.1.x will say this version's signature isn't valid,
because since 0.2.0 Aula is signed with new keys.

## What's new
- **Aula on your devices from Windows (#88, #87):** the Windows installer now bundles the embedded `aula-tsnet.exe`
  Tailscale component (x64 and ARM64). Enable **Settings → Aula on your devices** on your Windows PC, sign in to
  Tailscale and pair your Android phone, iPhone or iPad with a 6-digit code to access your existing courses, progress
  and settings directly — opt-in, tailnet-only, no Docker and no data migration.
- **Complete data reset:** *Delete all data* now also clears `Remote/` (paired device hashes and local Tailscale state),
  while keeping `Remote/` excluded from exports.
- **Windows updates and remote uploads:** ensures `aula-tsnet.exe` exits cleanly on app quit so Windows updates aren't
  blocked, and sanitizes NTFS reserved names and trailing dots/spaces in files uploaded from mobile devices.

## Install

On a Mac, download `Aula-0.2.9-mac.dmg`. The `Aula-0.2.5-mac.*` files on this page are only for older copies that
update through 0.2.5.

| System | Download | First launch |
| --- | --- | --- |
| macOS 13 or later (Apple Silicon and Intel) | `Aula-0.2.9-mac.dmg` | Drag Aula to *Applications* and open it. |
| Windows 10 and 11 (x64 and ARM) | `Aula-Setup-0.2.9.exe` | Aula isn't code-signed for Windows yet. If SmartScreen appears: *More info → Run anyway*. |
| Linux x64 | `Aula-0.2.9-linux-x86_64.AppImage` · `Aula-0.2.9-linux-amd64.deb` | `chmod +x` the AppImage and open it, or `sudo apt install ./Aula-0.2.9-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.2.9-linux-arm64.AppImage` | `chmod +x` the AppImage and open it. |
| Android 8 or later | `Aula-0.2.9-android.apk` | Open the file on the phone and allow installing from that app when Android asks. It needs Aula running on your Mac, Windows PC or server. |
| Server (Docker, x64 and ARM64) | `ghcr.io/luumlabs/aula-server:0.2.9` | `docker run -d --name aula --restart unless-stopped --shm-size=1g -v aula-data:/data ghcr.io/luumlabs/aula-server:0.2.9`, then `docker logs aula`. |

All the changes are in the [CHANGELOG](https://github.com/luumlabs/aula/blob/v0.2.9/CHANGELOG.md).

# Aula 0.2.9

Usa Aula en Windows como host privado por Tailscale para tu teléfono Android, iPhone y iPad —reutilizando directamente
tus cursos, tu progreso y tu configuración de Windows sin Docker ni otra instancia—, junto con mejoras de fiabilidad al
borrar datos, subir archivos desde móviles y actualizar en Windows.

Si tienes Aula 0.2.0 o posterior, se actualiza sola. En un Mac, las copias de la 0.2.0 a la 0.2.4 se actualizan
primero a la 0.2.5 y luego a la 0.2.9. **Si todavía tienes Aula 0.1.x, instala esta versión a mano esta única vez:**
descárgala abajo e instálala encima de tu copia (tus cursos y ajustes se quedan). Aula 0.1.x dirá que la firma de esta
versión no es válida, porque desde la 0.2.0 Aula va firmada con claves nuevas.

## Lo nuevo
- **Aula en tus dispositivos desde Windows (#88, #87):** el instalador de Windows incluye ahora el componente integrado
  de Tailscale (`aula-tsnet.exe`, x64 y ARM64). Activa **Ajustes → Aula en tus dispositivos** en tu PC con Windows,
  inicia sesión en Tailscale y vincula tu Android, iPhone o iPad con un código de 6 cifras para usar tus cursos, tu
  progreso y tus ajustes existentes: activación explícita, solo por tu red privada de Tailscale, sin Docker y sin migrar
  datos.
- **Borrado completo de datos:** *Eliminar todos los datos* borra ahora también `Remote/` (huellas de dispositivos
  vinculados y estado local de Tailscale), manteniendo `Remote/` fuera de las exportaciones.
- **Actualizaciones en Windows y subidas remotas:** asegura el cierre limpio de `aula-tsnet.exe` al salir para evitar
  bloqueos al actualizar en Windows y sanea nombres reservados de NTFS y puntos/espacios finales en archivos subidos
  desde dispositivos móviles.

## Instalar

En un Mac, descarga `Aula-0.2.9-mac.dmg`. Los archivos `Aula-0.2.5-mac.*` de esta página solo sirven para que las
copias antiguas se actualicen pasando por la 0.2.5.

| Sistema | Descarga | La primera vez |
| --- | --- | --- |
| macOS 13 o posterior (Apple Silicon e Intel) | `Aula-0.2.9-mac.dmg` | Arrastra Aula a *Aplicaciones* y ábrela. |
| Windows 10 y 11 (x64 y ARM) | `Aula-Setup-0.2.9.exe` | Aula aún no está firmada para Windows. Si aparece SmartScreen: *Más información → Ejecutar de todas formas*. |
| Linux x64 | `Aula-0.2.9-linux-x86_64.AppImage` · `Aula-0.2.9-linux-amd64.deb` | Haz ejecutable la AppImage (`chmod +x`) y ábrela, o `sudo apt install ./Aula-0.2.9-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.2.9-linux-arm64.AppImage` | Haz ejecutable la AppImage (`chmod +x`) y ábrela. |
| Android 8 o posterior | `Aula-0.2.9-android.apk` | Abre el archivo en el teléfono y permite instalar desde esa app cuando Android lo pregunte. Necesita Aula en marcha en tu Mac, en tu PC con Windows o en un servidor. |
| Servidor (Docker, x64 y ARM64) | `ghcr.io/luumlabs/aula-server:0.2.9` | `docker run -d --name aula --restart unless-stopped --shm-size=1g -v aula-data:/data ghcr.io/luumlabs/aula-server:0.2.9` y luego `docker logs aula`. |
