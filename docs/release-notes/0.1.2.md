# Aula 0.1.2

A small update for Windows and Linux. If you already have Aula, it updates itself.

## What's new
- Windows: checking for updates no longer fills Aula's log with a warning every time.
- Aula is now tested on real Windows and Linux machines (x64 and ARM) for every change, including installing the
  published installers and updating from the previous version.

## Install
| System | Download | First launch |
| --- | --- | --- |
| macOS 13 or later (Apple Silicon and Intel) | `Aula-0.1.2-mac.dmg` | Drag Aula to *Applications*. It isn't notarized yet: try to open it, then go to *System Settings → Privacy & Security → Open Anyway* (on macOS 14 and earlier, right-click → Open). |
| Windows 10 and 11 (x64 and ARM) | `Aula-Setup-0.1.2.exe` | If SmartScreen appears: *More info → Run anyway*. |
| Linux x64 | `Aula-0.1.2-linux-x86_64.AppImage` · `Aula-0.1.2-linux-amd64.deb` | `chmod +x` the AppImage and open it, or `sudo apt install ./Aula-0.1.2-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.1.2-linux-arm64.AppImage` | `chmod +x` the AppImage and open it. |

All the changes are in the [CHANGELOG](https://github.com/luumlabs/aula/blob/main/CHANGELOG.md).

# Aula 0.1.2

Una actualización pequeña para Windows y Linux. Si ya tienes Aula, se actualiza sola.

## Lo nuevo
- Windows: buscar actualizaciones ya no llena el registro de Aula con un aviso cada vez.
- Aula se prueba ahora en máquinas Windows y Linux de verdad (x64 y ARM) con cada cambio, incluida la instalación de los
  instaladores publicados y la actualización desde la versión anterior.

## Instalar
| Sistema | Descarga | La primera vez |
| --- | --- | --- |
| macOS 13 o posterior (Apple Silicon e Intel) | `Aula-0.1.2-mac.dmg` | Arrastra Aula a *Aplicaciones*. Aún no está notarizada: intenta abrirla y luego ve a *Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente* (en macOS 14 y anteriores, clic derecho → Abrir). |
| Windows 10 y 11 (x64 y ARM) | `Aula-Setup-0.1.2.exe` | Si aparece SmartScreen: *Más información → Ejecutar de todas formas*. |
| Linux x64 | `Aula-0.1.2-linux-x86_64.AppImage` · `Aula-0.1.2-linux-amd64.deb` | Haz ejecutable la AppImage (`chmod +x`) y ábrela, o `sudo apt install ./Aula-0.1.2-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.1.2-linux-arm64.AppImage` | Haz ejecutable la AppImage (`chmod +x`) y ábrela. |

Todos los cambios están en el [CHANGELOG](https://github.com/luumlabs/aula/blob/main/CHANGELOG.md) (en inglés).

**Código fuente:** los archivos *Source code* de esta versión (etiqueta `v0.1.2`) son el código exacto de estos
