# Aula 0.1.3

Choose your AI's model and how much it reasons, and always know when a course is still being created. If you already
have Aula, it updates itself.

## What's new
- **Your own AI service, for example Venice:** pick the model from the list the service gives (Settings → Your AI),
  instead of typing its exact name. Each model shows its context and whether it can reason.
- **Reasoning:** a picker under the model for every AI that lets you choose (Automatic, No reasoning, Low, Medium,
  High…).
- **Courses being created:** you can study the topics that are ready while Aula writes the rest, and now the sidebar
  and the course itself say so, with the progress, not only Today.

## Install
| System | Download | First launch |
| --- | --- | --- |
| macOS 13 or later (Apple Silicon and Intel) | `Aula-0.1.3-mac.dmg` | Drag Aula to *Applications*. It isn't notarized yet: try to open it, then go to *System Settings → Privacy & Security → Open Anyway* (on macOS 14 and earlier, right-click → Open). |
| Windows 10 and 11 (x64 and ARM) | `Aula-Setup-0.1.3.exe` | If SmartScreen appears: *More info → Run anyway*. |
| Linux x64 | `Aula-0.1.3-linux-x86_64.AppImage` · `Aula-0.1.3-linux-amd64.deb` | `chmod +x` the AppImage and open it, or `sudo apt install ./Aula-0.1.3-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.1.3-linux-arm64.AppImage` | `chmod +x` the AppImage and open it. |

All the changes are in the [CHANGELOG](https://github.com/luumlabs/aula/blob/main/CHANGELOG.md).

# Aula 0.1.3

Elige el modelo de tu IA y cuánto razona, y sabe siempre cuándo un curso aún se está creando. Si ya tienes Aula, se
actualiza sola.

## Lo nuevo
- **Tu propio servicio de IA, por ejemplo Venice:** elige el modelo de la lista que da el servicio (Ajustes → Tu IA),
  sin escribir su nombre exacto. Cada modelo dice su contexto y si puede razonar.
- **Razonamiento:** un selector bajo el modelo en cada IA que deja elegirlo (Automático, Sin razonamiento, Bajo,
  Medio, Alto…).
- **Cursos que se están creando:** puedes estudiar los temas que ya están listos mientras Aula escribe el resto, y
  ahora también lo dicen la barra lateral y el propio curso, con el progreso, no solo Hoy.

## Instalar
| Sistema | Descarga | La primera vez |
| --- | --- | --- |
| macOS 13 o posterior (Apple Silicon e Intel) | `Aula-0.1.3-mac.dmg` | Arrastra Aula a *Aplicaciones*. Aún no está notarizada: intenta abrirla y luego ve a *Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente* (en macOS 14 y anteriores, clic derecho → Abrir). |
| Windows 10 y 11 (x64 y ARM) | `Aula-Setup-0.1.3.exe` | Si aparece SmartScreen: *Más información → Ejecutar de todas formas*. |
| Linux x64 | `Aula-0.1.3-linux-x86_64.AppImage` · `Aula-0.1.3-linux-amd64.deb` | Haz ejecutable la AppImage (`chmod +x`) y ábrela, o `sudo apt install ./Aula-0.1.3-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.1.3-linux-arm64.AppImage` | Haz ejecutable la AppImage (`chmod +x`) y ábrela. |
