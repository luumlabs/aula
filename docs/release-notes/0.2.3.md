# Aula 0.2.3

The arch on Today comes alive, slowly, under your mouse.

If you have Aula 0.2.0 or later, it updates itself. **If you still have Aula 0.1.x, install this version by hand this
one time:** download it below and install it over your copy (your courses and settings stay). Aula 0.1.x will say this
version's signature isn't valid, because since 0.2.0 Aula is signed with new keys.

## What's new
- **The arch on Today moves in slow motion:** pass the mouse over the big ink-and-wash arch in Today's greeting and
  its layers (the wash, the colour, the light and the ink line) drift apart slowly, each at its own depth, while the
  light inside does what that hour's light does: the dawn sun grows, the noon sun and the moon rise, the evening sun
  sinks. Take the mouse away and it settles back just as slowly. With *Reduce motion* it stays still.

## Install
| System | Download | First launch |
| --- | --- | --- |
| macOS 13 or later (Apple Silicon and Intel) | `Aula-0.2.3-mac.dmg` | Drag Aula to *Applications*. It isn't notarized yet: try to open it, then go to *System Settings → Privacy & Security → Open Anyway* (on macOS 14 and earlier, right-click → Open). |
| Windows 10 and 11 (x64 and ARM) | `Aula-Setup-0.2.3.exe` | If SmartScreen appears: *More info → Run anyway*. |
| Linux x64 | `Aula-0.2.3-linux-x86_64.AppImage` · `Aula-0.2.3-linux-amd64.deb` | `chmod +x` the AppImage and open it, or `sudo apt install ./Aula-0.2.3-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.2.3-linux-arm64.AppImage` | `chmod +x` the AppImage and open it. |

All the changes are in the [CHANGELOG](https://github.com/luumlabs/aula/blob/main/CHANGELOG.md).

# Aula 0.2.3

El arco de Hoy cobra vida, despacio, bajo tu ratón.

Si tienes Aula 0.2.0 o posterior, se actualiza sola. **Si todavía tienes Aula 0.1.x, instala esta versión a mano esta
única vez:** descárgala abajo e instálala encima de tu copia (tus cursos y ajustes se quedan). Aula 0.1.x dirá que la
firma de esta versión no es válida, porque desde la 0.2.0 Aula va firmada con claves nuevas.

## Lo nuevo
- **El arco de Hoy se mueve a cámara lenta:** pasa el ratón por el arco grande a tinta y acuarela del saludo de Hoy y
  sus capas (la aguada, el color, la luz y la tinta) se separan despacio, cada una a su profundidad, mientras la luz
  de dentro hace lo que toca a esa hora: el sol del amanecer crece, el del mediodía y la luna suben, el de la tarde
  se hunde. Quita el ratón y vuelve a su sitio igual de despacio. Con *Reducir movimiento* se queda quieto.

| Windows 10 y 11 (x64 y ARM) | `Aula-Setup-0.2.3.exe` | Si aparece SmartScreen: *Más información → Ejecutar de todas formas*. |
